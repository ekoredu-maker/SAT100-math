# SAT100-math — 수능핏 MATH

아이패드 홈 화면에 설치해 사용하는 **수능 수학 1등급 목표 PWA**입니다.

## 핵심 학습 전략

### 1단계: 수능 D-31까지
- 공통 **14·15·21·22번**, 미적분 **28·30번** 중심
- 최근 5개년 수능 + 올해 6월·9월 평가원 모의평가의 주요 4점 사고구조를 우선 학습
- EBS 연계·변형 신호를 보조적으로 반영
- 쉬운 2~3점형보다 1등급을 가르는 4점형에 집중
- 정복 기준: **정답 + 확신 + 힌트 미사용 + 적정 시간**

### 2단계: 수능 D-30부터
- 최근 기출의 사고 DNA를 유지하면서 조건·표현·구조를 비튼 **기출 변형 문제** 중심
- 기본 7문제 중 약 5문제를 변형 문제로 구성
- 나머지는 1단계에서 틀렸거나 불확실했던 문제를 복습

## v2.3 기출 계보

앱의 문제는 실제 평가원 기출 원문을 그대로 복제한 것이 아닙니다.

각 문항을 **기출 핵심형(재구성)** 또는 **기출 변형**으로 구분하고,
최근 수능·6월·9월 모의평가에서 같은 사고구조가 출제된 문항의
`학년도 / 시험 / 문항번호 / 핵심 DNA / EBS 공식 분석 링크`를 함께 제공합니다.

학생이 시험장에서 처음 보는 문제를 만났을 때
**“표현은 처음이지만 구조는 풀어 본 것이다.”**라고 느끼게 하는 것이 목표입니다.

## 예측 원칙

- CORE: 최근 평가원·수능에서 반복 검증된 사고구조
- EBS WATCH: 현재 EBS 연계교재에서 강하게 보이는 변형 후보
- 같은 단원이 나왔다고 적중으로 판단하지 않음
- 실제 풀이에 핵심 사고요소가 결합되어 나타나는지를 기준으로 평가
- 출제 우선지수는 확률이 아니라 **상대 우선순위**

## PWA / 오프라인

- `manifest.webmanifest` + `sw.js` 기반 standalone PWA
- 서비스워커가 앱 셸, 아이콘, v2.2 운영패치, v2.3 기출계보 레이어를 캐시
- 학습 기록과 오답, 진도는 서버가 아니라 기기의 localStorage에 저장
- 설정 → 백업에서 학습 데이터를 JSON으로 내보낼 수 있음

## 아이패드 설치

1. Safari에서 `https://ekoredu-maker.github.io/SAT100-math/` 접속
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행

업데이트 후에는 앱을 완전히 종료하고 다시 열거나 Safari에서 한 번 새로고침하면 새 서비스워커가 적용됩니다.

## 현재 운영 목표
