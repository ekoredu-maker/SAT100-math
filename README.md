# SAT100-math — 수능핏 MATH (아이패드 PWA)

수능 수학 1등급을 목표로, 최근 수능·평가원 4점 문항의 핵심 사고구조를 익힌 뒤 수능 30일 전부터 기출 변형 실전으로 전환하는 학습 앱입니다.

## v2.2 학습 전략

### 1단계 · D-31까지

- 집중 번호: **14·15·21·22·28·30번**
- 쉬운 `secure` 문항은 오늘 세트에서 제외
- 최근 수능·6월·9월 모평의 반복 사고 DNA와 EBS 핵심 신호를 반영한 **4점 기출 핵심형**을 우선 학습
- 한 번 맞힌 것으로 끝내지 않고 아래를 모두 만족해야 **정복**으로 계산
  - 정답
  - `확신` 선택
  - 힌트 미사용
  - 기준시간의 135% 이내
- 기본 7문제라면 여섯 번호에서 최소 1문제씩 균형 있게 배정하고, 남은 1문제는 CORE·EBS WATCH·개인 취약도·복습 도래를 함께 반영

### 2단계 · D-30부터 (2026-10-20)

- 최근 기출 DNA를 비튼 **기출 변형** 중심
- 기본 7문제 중 약 5문제를 변형문제로 편성
- 나머지는 1단계에서 틀렸거나, 힌트를 썼거나, 확신하지 못했거나, 시간이 오래 걸린 문제를 회수
- 변형문제도 14·15·21·22·28·30번 자리가 한쪽으로 몰리지 않도록 순환 배정

> CORE는 여러 시험의 반복 역검증을 통과한 상대 우선순위이고, EBS WATCH는 현재 EBS 연계·변형 신호를 놓치지 않기 위한 별도 감시축입니다. 둘 다 출제확률 자체를 뜻하지 않습니다.

## 왜 웹에 올려야 하나요

학습 기록은 기기 안 `localStorage`에 저장됩니다. 파일로 직접 열기보다 GitHub Pages로 배포하고 아이패드 홈 화면에 추가해 사용하는 편이 오프라인 캐시와 업데이트 관리에 안정적입니다.

## GitHub Pages 배포

1. GitHub 저장소를 만들고 Pages를 `main / root`로 설정합니다.
2. 저장소 루트에 다음 파일을 둡니다.
   - `index.html`
   - `patch-v2.2.js`
   - `manifest.webmanifest`
   - `sw.js`
   - `icons/` 폴더
3. Pages 주소를 Safari에서 열어 **홈 화면에 추가**합니다.

현재 배포 주소:
`https://ekoredu-maker.github.io/SAT100-math/`

## 오프라인과 업데이트

- `sw.js`가 앱 셸과 `patch-v2.2.js`를 캐시합니다.
- HTML은 네트워크 우선으로 갱신하고, 연결이 없으면 마지막 캐시를 사용합니다.
- 서비스워커 버전은 `suneungfit-v2-2-0`입니다.
- 새 버전이 올라온 뒤에는 Safari/PWA를 완전히 닫았다 다시 열거나 한 번 새로고침하면 반영됩니다.

## 공개 저장소와 개인정보

저장소에 올라가는 것은 앱 코드와 문제 데이터입니다. 풀이 기록·오답·진도는 사용 중인 기기의 브라우저 저장소에 남고 GitHub 저장소로 전송되지 않습니다.

## 학습 기록 백업

앱 안 **설정 → 백업**에서 기록을 내보낼 수 있습니다. 중요한 시험 전에는 주기적으로 백업하는 것을 권장합니다.

## 개발 원칙

- 문제 수보다 **수학적 정합성**을 우선
- 같은 단원이 나왔다고 예측 적중으로 계산하지 않음
- 조건이 여러 개라면 조건 간 상호작용이 실제 풀이에 필요하도록 설계
- 수능 출제우선도와 학생 개인 취약도는 분리
- 수능 D-30 전후로 학습 목적을 명확히 전환
- 실제 기출 원문을 무분별하게 복제하기보다, 최근 수능·모평의 핵심 사고구조를 검증해 학습문제와 변형문제로 재구성
