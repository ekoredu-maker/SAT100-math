# SAT100-math — 수능핏 수학 (아이패드 PWA)

딸의 아이패드 홈 화면에 앱처럼 설치해서 쓰는 수능 수학 학습 앱입니다.

## 왜 웹에 올려야 하나요

Safari는 7일 동안 그 사이트를 쓰지 않으면 localStorage를 포함한 저장 데이터를 자동 삭제합니다.
학습 기록이 전부 localStorage에 있어서, 파일로 열어 쓰면 기록이 날아갈 수 있습니다.
**홈 화면에 추가한 웹 앱은 이 정책에서 제외**되므로, 웹에 올려 홈 화면에 설치하는 것이 안전합니다.

---

## 1단계 — GitHub에 올리기 (5분)

1. GitHub에서 **New repository** 클릭
2. Repository name: **`SAT100-math`**  (대소문자 그대로)
3. **Public** 선택 (무료 플랜은 공개 저장소만 Pages 사용 가능)
4. **Create repository**
5. 저장소 화면에서 **Add file → Upload files**
6. 이 폴더의 내용물을 **통째로** 끌어다 놓기
   - `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` 폴더
   - ⚠️ 폴더째 올릴 때 `icons` 폴더가 같이 올라갔는지 확인하세요
7. **Commit changes**

## 2단계 — Pages 켜기 (1분)

1. 저장소 **Settings** → 왼쪽 메뉴 **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 주소가 생깁니다:
   `https://<내아이디>.github.io/SAT100-math/`

## 3단계 — 아이패드 홈 화면에 설치

1. **Safari로** 위 주소 열기 (크롬 말고 Safari여야 합니다)
2. 하단/상단 **공유 버튼** 탭
3. **홈 화면에 추가** 선택
4. 이름 확인 후 **추가**

이제 홈 화면 아이콘으로 실행됩니다. 주소창 없이 전체화면으로 뜨고, 비행기 모드에서도 열립니다.

---

## 공개 저장소인데 괜찮나요

올라가는 건 **앱 코드와 문제뿐**입니다.
딸의 풀이 기록·오답·진도는 아이패드 안에만 저장되고 서버로 전송되지 않습니다.

## 나중에 문제를 추가하거나 고칠 때

`index.html` 한 파일만 교체하면 됩니다.
GitHub에서 파일 클릭 → 연필 아이콘 → 내용 교체 → Commit.
아이패드에서는 앱을 껐다 켜면 1~2분 내로 새 버전이 반영됩니다.

## 학습 기록 백업

앱 안 **설정 → 백업**에서 기록을 파일로 내보낼 수 있습니다.
시험 전까지 가끔 백업해두시면 기기를 바꾸거나 문제가 생겨도 복구됩니다.
